# Skizzen der Seiten (Abläufe)
Jede Seite: einstieg (Szene, Einzelauswahl, Ich-kann, Wörter-Tabelle) → neu (Streifen-Figur, Merke, Poster) → uebung (zuordnen/Lücke → ordnen → schreiben → Diktat → Nachsprechen) → anwenden (open-task) → weiter.
Nach einer Übung sieht das Kind je Antwort die eigene Rückmeldung; ein Hinweis nennt die Regel, nie nur die Lösung.
Szenen: Klassenzimmer, Satzstreifen-Wand hinten, Figuren aus millbrook-klassenzimmer.svg. Bilder: konjunktionen.svg, that-saetze.svg, relativsaetze.svg, weiche.svg.
